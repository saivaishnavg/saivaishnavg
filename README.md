## 🚀 Featured Projects

### 🫀 Cloud-Based ECG Signal Analysis for Real-Time Cardiac Rhythm Monitoring

An ECG monitoring system combining an AD8232 ECG sensor, ESP32 microcontroller, Python-based prediction backend, and cloud connectivity to support real-time cardiac signal monitoring.

**Key Contributions**
- Integrated ECG sensor hardware with the ESP32.
- Developed the Python prediction component.
- Worked on real-time signal transmission and monitoring.

**Technologies:** Python, ESP32, AD8232, Node.js, Express, MongoDB, AWS EC2.

[View Project →](https://github.com/saivaishnavg/Cloud_Based_ECG_Signal_Analysis_for_Real_Time_Cardiac_Rhythm_Monitoring_Using_AI)

### 🐾 Animal Voice Detection and Classification System

A machine learning project that processes animal audio recordings and classifies sounds using audio feature extraction and transfer learning.

**Key Features**
- Audio processing and feature extraction.
- Dataset preparation and analysis.
- Model-based animal sound classification.

**Technologies:** Python, Librosa, NumPy, Pandas, MobileNetV2.

[View Project →](https://github.com/saivaishnavg/Animal-Voice-Detection-and-Classification-System)

### 🤖 Real-Time Obstacle Avoidance System Using QNX RTOS

An embedded systems project focused on detecting obstacles using an ultrasonic sensor and implementing real-time responses.

**Technologies:** QNX RTOS, Raspberry Pi 4, HC-SR04 ultrasonic sensor, QNX IPC, Momentics IDE.
